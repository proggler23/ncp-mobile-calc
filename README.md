# NCP Mobile Calc

Mobile-first PWA rebuild of the NCP VGC Damage Calculator (Phase 1: scaffolding).

## Scripts

`dev`, `build`, `preview`, `lint`, `typecheck`, `test`, `test:e2e`, `format`.

Set `VITE_BASE` (e.g. `/repo-name/`) for GitHub Pages subpath builds.

Data refresh, NCP upstream sync, validation gates and the automatic deploy are described in
[docs/MAINTENANCE.md](docs/MAINTENANCE.md).
